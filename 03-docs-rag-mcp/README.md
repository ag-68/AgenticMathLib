# docs-rag-mcp

An MCP server that gives agents on-demand access to library documentation built from installed-package docstrings, and measures whether lookup reduces invented arguments.

## Status

**In progress** (2026-10-12). Repository skeleton only. Milestones M1 through M4 have not started.

## What works

The package `docs_rag_mcp` imports. The project specification is in `SPEC.md`.

## What does not work yet

The corpus builder, BM25, embedding, and hybrid retrievers, the three MCP tools, and the agent evaluation are not implemented.
