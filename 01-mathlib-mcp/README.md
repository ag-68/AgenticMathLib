# mathlib-mcp

Eight numerical tools, plus array handles, offered to AI agents with descriptions and errors designed for correct use. A stand-in for the same work on libraries such as cuFFT, cuBLAS, cuSOLVER, and cuSPARSE.

**In progress** (2026-10-12). Repository skeleton only. Milestones M1, M2, M3, and M4 have not started.

## What works

The package `mathlib_mcp` imports. The project specification is in `SPEC.md`.
